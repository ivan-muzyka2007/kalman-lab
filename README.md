# kalman-lab — оценка состояния БПЛА по логам полётного контроллера

Учебно-исследовательский проект: читаю логи ArduPilot, разбираю данные
датчиков и пишу собственный фильтр Калмана для оценки высоты и скорости,
сравнивая результат со штатным фильтром автопилота (EKF3).

**Статус:** неделя 2 из 12. Сделано: окружение, терминал, git.
**Автор:** Иван Музыка, город Москва

---

## Зачем это
При потере сигнала ГНСС автопилоту приходится оценивать положение
только по инерциальным датчикам и барометру. Я проверяю, насколько точную
оценку даёт собственный фильтр Калмана на реальных логах полёта и при каких
условиях он перестаёт работать. Результат — сравнение с EKF3 по метрикам
(RMSE, максимальное отклонение) на сценариях деградации датчиков.

## Как запустить

Требуется: Ubuntu (или WSL2), Python 3.10+, виртуальное окружение.

```bash
# 1. окружение
python3 -m venv ~/projects/uavenv
source ~/projects/uavenv/bin/activate
pip install -r requirements.txt

# 2. проверка, что всё на месте
python src/check_env.py

# 3. сгенерировать демонстрационные данные (лого в наличии не требуется)
python src/logdata.py --demo

# 4. графики по демо-данным
python src/plot_basic.py --demo --out figures/demo.png
```
